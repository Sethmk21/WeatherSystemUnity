# WeatherSystemUnity
This is a weather system I made for Lil' Quests, my game design capstone project. 
In this repo, you will find the base class for a weather state that you can use to make new weather states. In Lil' Quests, I used it to create multiple weather states, for example, a stormy state with lightning, a snowy state that made the ground slippery, and many others you can use as examples for your own projects.

# How it works
This weather system is a simple State machine that's found within the day manager. My implementation of this is based off time of day, a float that affects the brightness and rotation of the directional light, and when weather states change. In the start function, we begin with the disired statring stat by calling the State state function and then in the fixed update function The DoWeather function is called to handle any logic that needs to run during the state repeditivly and final when its time to change the state the GetNextState Function is called to do any cleanup needed after a state is completed and select the next state randomly from a set of specified weather states. A lot of the weather states that I use run alongside multiple particle systems, for example, rain with the PouringState, which is managed with a reference to a parent object of multiple particle systems, and a script called ChangeRainAmount that allows you to control how much the particle systems are emitting and gradually fade them out at the end of the state
