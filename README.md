# WeatherSystemUnity
This is a weather system I made for Lil' Quests, my game design capstone project. 
In this repo, you will find the base class for a weather state that you can use to make new weather states. In Lil' Quests, I used it to create multiple weather states, for example, a stormy state with lightning, a snowy state that made the ground slippery, and many others you can use as examples for your own projects.

# How it works
This weather system is a simple State machine that's found within the day manager
